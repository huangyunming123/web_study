# CRM 客户关系与全渠道运营微服务管理系统

本项目是基于 Spring Boot 3 与 Vue 3 技术栈重构的全栈企业级 **CRM 运营管理系统**。集成权限分配、订单全生命周期追踪、商品全链路管理、物流配货出库与轨迹追踪等企业核心场景。

---

## 🛠️ 模块职责与技术栈

| 模块名称 | 职责定位 | 核心技术栈 | 监听端口 |
| :--- | :--- | :--- | :--- |
| **Nginx 网关** | 外层统一接入网关 (前端静态托管 + 接口反向代理) | Nginx 1.25+ (Alpine), Gzip, Vue History 路由支持 | `:80` |
| **中间件** | 数据库与缓存持久化 | MySQL 8.0, Redis 7 (Docker Compose 编排，utf8mb4 编码) | 3306, 6379 |
| **gateway** | 纯转发微服务网关 (透明代理/透传请求 Body 与 Headers) | Spring Boot 3.3.x, RestTemplate, JDK 21 | `:8080` |
| **auth-service** | 鉴权微服务 (注册、登录、BCrypt、JJWT 会话) | Spring Boot 3.3.x, 原生 MyBatis 3.0.x, JJWT 0.12.x, Knife4j | `:8081` |
| **biz-service** | CRM 核心业务微服务 (订单/商品发布/物流发货/用户与权限分配) | Spring Boot 3.3.x, 原生 MyBatis 3.0.x, **Redisson 分布式锁**, Redis 缓存, HandlerInterceptor | `:8082` |
| **web** | CRM 现代化管理后台前端 | Vue 3, Vite 5, Element Plus, Pinia, Vue Router 4, Axios | `:5173` (开发) / `:80` (生产) |

## 🚀 CRM 核心功能模块

1. **订单管理 (`/order`)**：
   * 多维度综合查询：支持订单号、客户姓名、手机号、订单状态（待支付、待发货、已发货、已完成、已取消）及创建日期范围过滤。
   * 订单明细抽屉：包含下单客户基本信息、收件地址、购买商品明细清单快照及绑定承运商物流卡片。
   * 待发货订单快捷出库入口。

2. **商品中心 (`/product`)**：
   * 商品多条件查询：支持类目（数码电子、电脑办公、影音娱乐、智能家居等）、上下架状态过滤与名称模糊搜索。
   * 商品发布与编辑：录入名称、类目、价格、库存、上下架状态与详细图文规格说明。
   * 高并发防超卖保障：秒杀下单集成 **Redisson 分布式互斥锁** 与 **数据库原子减库存** 双重兜底，自动维护 Redis 缓存一致性。

3. **物流中心 (`/logistics`)**：
   * 物流出库配货：支持为待发货订单选择承运商（顺丰速运、京东快递、中通、圆通、极兔等）、自动生成或录入快递单号、经办人。
   * 全链路流转轨迹时间轴：基于 `el-timeline` 动态追踪包裹出库、分拣、干线转运、同城派送与客户签收。

4. **用户与权限分配中心 (`/user` & `/role`)**：
   * 用户综合查询：查看用户账号、昵称、手机号、状态及拥有的多角色标签。
   * 细粒度角色权限分配：支持为指定用户快速勾选/解除角色；支持在权限矩阵中为角色勾选菜单与按钮级操作权限。

## ⚡ 极速启动与验证

1. **构建前端产物**：
   ```bash
   cd F:\webDemo\web
   pnpm run build
   ```
2. **启动中间件与 Nginx 容器**：
   ```bash
   cd F:\webDemo
   docker compose up -d
   ```
3. **启动微服务**：在 IDEA 中启动 `auth-service` (8081)、`biz-service` (8082)、`gateway` (8080)；
4. **统一访问**：浏览器访问 **`http://localhost`**（或开发模式 `http://localhost:5173`）登录即可体验完整 CRM 运营系统。
